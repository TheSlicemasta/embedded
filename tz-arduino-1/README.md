# Тестове завдання: Низькорівневе дискретне управління ШІМ через АЦП для Arduino Nano

Цей проект реалізує зчитування аналогового сигналу з потенціометра з частотою 100 Гц, його цифрову фільтрацію методом ковзного середнього по 8 точках та керування тривалістю світла світлодіоду апаратним ШИМ-сигналом з частотою 1 Гц.

Конфігурація периферії (GPIO, ADC, Timer1, Timer2) виконана без використання стандартних функцій Arduino (`analogRead`, `analogWrite`, `pinMode`, `delay`) та реалізована на рівні прямої роботи з регістрами мікроконтролера (**Bare-Metal/Low-Level підхід**). Основний цикл програми є повністю неблокуючим та працює за подіями готовності АЦП. Для внутрішньої налагодження та візуалізації роботи алгоритму інтегровано відстеження 5 функціональних зон потенціометра з виведенням текстових логів в `Serial` (прибрано та замінено на хелпери: uart_init, uart_print_char, uart_print_str, uart_print_num - соотв.

## 1. Апаратна конфігурація
* **Плата:** Arduino Nano V3.0
* **Мікроконтролер:** ATmega328P (Тактова частота **16 МГц**)
* **Аналоговий вхід:** Вивiд **A0** (Порт `PC0`, канал `ADC0`) - підключення центрального виведення потенціометра (наприклад, багатооборотного Baoter 3296 W103).
* **Вихід ШИМ:** Вивiд **D9** (Порт `PB1`, апаратний вихід `OC1A` Таймера 1) - підключення світлодіода через обмежувальний резистор.

## 2. Схема підключення
```text 
[ Arduino Nano ] 
+----------------+ 

| A0 | <--- Вивiд 2 (середній) потенціометра Baoter 3296 
| D9 | ---> [Резистор 220 Ом] ---> [Анод Світлодіода (+)] 
| 5V | ---> Вивiд 3 потенціометри 
| GND | ---> Виведення 1 потенціометра & Катод світлодіода (-) 
+----------------+
````
*Примітка по потенціометру Baoter 3296 W103: Виводи 1, 2, 3 розташовані зліва направо, якщо дивитися на фронтальну сторону корпусу з маркуванням.*

## 3. Розрахунок параметрів периферії та дискретних зон ШІМ

### А. Апаратний ШИМ 1 Гц (Timer1)
Використовується 16-бітний Timer1 у режимі Fast PWM (Mode 14), де верхня межа рахунку (TOP) задається регістром ICR1.
Формула частоти ШІМ:
\[f_{PWM} = \frac{f_{CLK}}{N \times (1 + ICR1)}\]

При тактовій частоті \(f_{CLK} = 16\000\000\) Гц і максимальному апаратному розподільнику N = 1024:
\[1\text{ Гц} = \frac{16\ 000\ 000}{1024 \times (1 + ICR1)} \implies 1 + ICR1 = 15625 \implies ICR1 = 15624\]

### Б. Таблиця функціональних зон потенціометра та роботи ШІМ
Відповідно до технічного завдання, весь діапазон 10-бітного відфільтрованого значення АЦП (\(0 \dots 1023\)) розділений на 5 рівних дискретних зон для візуальної перевірки коефіцієнта заповнення ШІМ на частоті 1 Гц без осцилографа:

| Зона | Діапазон АЦП Заповнення ШІМ | Значення OCR1A | Опис поведінки світлодіода за цикл 1 с
| :---: | :---: | :---: | :---: | :--- |
| **1** | 0 – 204 | **0%** | - | **Не світиться взагалі.** Апаратний ШІМ вимкнений (`COM1A1` = 0), на порту `PB1` утримується низький логічний рівень. |
| **2** | 205 – 409 | **25%** | **3906** | **Світиться ~0.25 с, не світиться 0.75 с.** Апаратний ШІМ увімкнений. Розрахунок: \ (15624 \ times 0.25 = 3906 \). |
| **3** | 410 – 614 | **50%** | **7812** | **Світиться ~0.50 с, не світиться 0.50 с.** Апаратний ШІМ увімкнений. Розрахунок: \ (15624 \ times 0.50 = 7812 \). |
| **4** | 615 – 819 | **75%** | **11718** | **Світиться ~0.75 с, не світиться 0.25 с.** Апаратний ШІМ увімкнений. Розрахунок: \ (15624 \ times 0.75 = 11718 \). |
| **5** | 820 – 1023 | **100%** | - | **Світиться постійно.** Апаратний ШІМ вимкнено (`COM1A1` = 0), на порту `PB1` виставлено постійний високий логічний рівень. |

### В. Вибірка АЦП 100 Гц (Timer2)
Для забезпечення періодичності вимірювань АЦП кожні 10 мс (100 Гц) використовується 8-бітний Timer2 в режимі CTC (Mode 2).
При предделителе N = 1024 частота тактування таймера становить 16000000 / 1024 = 15625 Гц.
\[OCR2A = \frac{15625}{100} - 1 = 155.25 \approx 155\]

## 4. Опис архітектурних рішень коду
* **Чесні 0% та 100% заповнення ШІМ:** У режимі Fast PWM запис значень `0` або `TOP` в регістр порівняння залишає короткі паразитні імпульси на виході через особливості роботи апаратного компаратора. Для реалізації абсолютно чистого відключення світлодіода (0%) та безперервного світіння (100%) у коді застосовано динамічне перемикання біта `COM1A1` регістру `TCCR1A`. У крайніх зонах виведення `PB1` тимчасово відключається від генератора ШІМ таймера та переводиться під управління регістру даних порту (`PORTB`).
* **Атомарність даних (Race Condition Prevention):** Регістр даних АЦП (`ADC`) та змінна `adc_raw_value` є 16-бітними. Оскільки ATmega328P - це 8-бітний процесор, операція копіювання даних в основному циклі займає кілька тактів. Для запобігання зчитування "битого" значення (якщо переривання АЦП оновить змінну прямо посередині процесу її копіювання) операція захищена критичною секцією за допомогою інструкцій `cli()` та `sei()`.
* **Синхронізація на межі періоду:** Зміни значень тривалості імпульсу в регістрах `OCR1A` буферизуються апаратно архітектурою AVR. При зміні зон в switch-case нове значення спрацює плавно і строго на межі поточного секундного періоду таймера ШІМ, виключаючи «мерехтіння» і глітчі.
* **Налагоджувальне логування:** В основному циклі обробляється виведення поточного відфільтрованого значення АЦП і текстовий опис поточної активної зони в Монітор порту. Робота з рядками не блокує тактування таймерів завдяки перериванням, що опрацьовують низькорівневі апаратні завдання.

## 5. Інструкція із запуску
1. Підключіть плату Arduino Nano до комп'ютера через кабель USB.
2. Зберіть схему (Розділ 2), підключивши потенціометр та світлодіод через резистор.
3. Відкрийте проект у IDE (Arduino IDE, VS Code + PlatformIO).
4. Завантажте код у мікроконтролер.
5. Відкрийте вбудований Монітор порту (Serial Monitor) та виберіть швидкість **9600 бод**.
6. Плавно обертайте гвинт потенціометра Baoter 3296. Спостерігайте у вікні терміналу за зміною filtered_adc і перемиканням текстових зон, паралельно фіксуючи візуальну відповідність тривалості фаз свічення світлодіода згідно таблиці.
