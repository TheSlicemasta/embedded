# Тестовое задание: Низкоуровневое дискретное управление ШИМ через АЦП для Arduino Nano

Этот проект реализует считывание аналогового сигнала с потенциометра с частотой 100 Гц, его цифровую фильтрацию методом скользящего среднего по 8 точкам и управление длительностью свечения светодиода аппаратным ШИМ-сигналом с частотой 1 Гц.

Конфигурация периферии (GPIO, ADC, Timer1, Timer2) выполнена без использования стандартных функций Arduino (`analogRead`, `analogWrite`, `pinMode`, `delay`) и реализована на уровне прямой работы с регистрами микроконтроллера (**Bare-Metal / Low-Level подход**). Основной цикл программы является полностью неблокирующим и работает по событиям готовности АЦП. Для внутренней отладки и визуализации работы алгоритма интегрировано отслеживание 5 функциональных зон потенциометра с выводом текстовых логов в `Serial` (убрано и заменено на хелперы: uart_init, uart_print_char, uart_print_str, uart_print_num - соотв LL подходу).

## 1. Аппаратная конфигурация
*   **Плата:** Arduino Nano V3.0
*   **Микроконтроллер:** ATmega328P (Тактовая частота **16 МГц**)
*   **Аналоговый вход:** Вывод **A0** (Порт `PC0`, канал `ADC0`) — подключение центрального вывода потенциометра (например, многооборотного Baoter 3296 W103).
*   **Выход ШИМ:** Вывод **D9** (Порт `PB1`, аппаратный выход `OC1A` Таймера 1) — подключение светодиода через ограничительный резистор.

## 2. Схема подключения
```text
          [ Arduino Nano ]
         +----------------+

         |             A0 | <--- Вывод 2 (средний) потенциометра Baoter 3296
         |             D9 | ---> [Резистор 220 Ом] ---> [Анод Светодиода (+)]
         |            5V  | ---> Вывод 3 потенциометра
         |            GND | ---> Вывод 1 потенциометра & Катод светодиода (-)
         +----------------+
```
*Примечание по потенциометру Baoter 3296 W103: Выводы 1, 2, 3 расположены слева направо, если смотреть на фронтальную сторону корпуса с маркировкой.*

## 3. Расчет параметров периферии и дискретных зон ШИМ

### А. Аппаратный ШИМ 1 Гц (Timer1)
Используется 16-битный **Timer1** в режиме **Fast PWM (Mode 14)**, где верхняя граница счета (`TOP`) задается регистром `ICR1`. 
Формула частоты ШИМ:
\[f_{PWM} = \frac{f_{CLK}}{N \times (1 + ICR1)}\]

При тактовой частоте \(f_{CLK} = 16\ 000\ 000\) Гц и максимальном аппаратном предделителе N = 1024:
\[1\text{ Гц} = \frac{16\ 000\ 000}{1024 \times (1 + ICR1)} \implies 1 + ICR1 = 15625 \implies ICR1 = 15624\]

### Б. Таблица функциональных зон потенциометра и работы ШИМ
В соответствии с техническим заданием, весь диапазон 10-битного отфильтрованного значения АЦП (\(0 \dots 1023\)) разделен на 5 равных дискретных зон для визуальной проверки коэффициента заполнения ШИМ на частоте 1 Гц без осциллографа:

| Зона | Диапазон АЦП | Заполнение ШИМ | Значение OCR1A | Описание поведения светодиода за цикл 1 с |
| :---: | :---: | :---: | :---: | :--- |
| **1** | 0 – 204 | **0%** | — | **Не светится вообще.** Аппаратный ШИМ отключен (`COM1A1` = 0), на порту `PB1` удерживается низкий логический уровень. |
| **2** | 205 – 409 | **25%** | **3906** | **Светится ~0.25 с, не светится 0.75 с.** Аппаратный ШИМ включен. Расчет: \(15624 \times 0.25 = 3906\). |
| **3** | 410 – 614 | **50%** | **7812** | **Светится ~0.50 с, не светится 0.50 с.** Аппаратный ШИМ включен. Расчет: \(15624 \times 0.50 = 7812\). |
| **4** | 615 – 819 | **75%** | **11718** | **Светится ~0.75 с, не светится 0.25 с.** Аппаратный ШИМ включен. Расчет: \(15624 \times 0.75 = 11718\). |
| **5** | 820 – 1023 | **100%** | — | **Светится постоянно.** Аппаратный ШИМ отключен (`COM1A1` = 0), на порту `PB1` выставлен постоянный высокий логический уровень. |

### В. Выборка АЦП 100 Гц (Timer2)
Для обеспечения периодичности измерений АЦП каждые 10 мс (100 Гц) используется 8-битный **Timer2** в режиме **CTC (Mode 2)**.
При предделителе N = 1024 частота тактования таймера составляет 16 000 000 / 1024 = 15625 Гц.
\[OCR2A = \frac{15625}{100} - 1 = 155.25 \approx 155\]

## 4. Описание архитектурных решений кода
*   **Честные 0% и 100% заполнения ШИМ:** В режиме Fast PWM запись значений `0` или `TOP` в регистр сравнения оставляет короткие паразитные импульсы на выходе из-за особенностей работы аппаратного компаратора. Для реализации абсолютно чистого отключения светодиода (0%) и непрерывного свечения (100%) в коде применено динамическое переключение бита `COM1A1` регистра `TCCR1A`. В крайних зонах вывод `PB1` временно отключается от генератора ШИМ таймера и переводится под управление регистра данных порта (`PORTB`).
*   **Атомарность данных (Race Condition Prevention):** Регистр данных АЦП (`ADC`) и переменная `adc_raw_value` являются 16-битными. Поскольку ATmega328P — это 8-битный процессор, операция копирования данных в основном цикле занимает несколько тактов. Для предотвращения считывания «битого» значения (если прерывание АЦП обновит переменную прямо посередине процесса её копирования) операция защищена критической секцией с помощью инструкций `cli()` и `sei()`.
*   **Синхронизация на границе периода:** Изменения значений длительности импульса в регистрах `OCR1A` буферизируются аппаратно архитектурой AVR. При смене зон в `switch-case` новое значение сработает плавно и строго на границе текущего секундного периода таймера ШИМ, исключая «мерцания» и глитчи.
*   **Отладочное логирование:** В основном цикле обрабатывается вывод текущего отфильтрованного значения АЦП и текстовое описание текущей активной зоны в Монитор порта. Работа со строками не блокирует тактирование таймеров благодаря прерываниям, обрабатывающим низкоуровневые аппаратные задачи.

## 5. Инструкция по запуску
1. Подключите плату Arduino Nano к вашему компьютеру через USB-кабель.
2. Соберите схему (Раздел 2), подключив потенциометр и светодиод через резистор.
3. Откройте проект в вашей IDE (Arduino IDE, VS Code + PlatformIO).
4. Загрузите код в микроконтроллер.
5. Откройте встроенный Монитор порта (Serial Monitor) и выберите скорость **9600 бод**.
6. Плавно вращайте винт потенциометра Baoter 3296. Наблюдайте в окне терминала за изменением `filtered_adc` и переключением текстовых зон, параллельно фиксируя визуальное соответствие длительности фаз свечения светодиода согласно таблице.
